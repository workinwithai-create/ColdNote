# ColdNote

Cold-ear pass for the sour note you stopped hearing.

A live FluidR3 band — grand piano, nylon guitar, upright bass, trumpet, and kit — plays an eight-bar chart with one pitch a half-step off. Solo a chair, mark the bar, name the instrument. The band plays the bar sour, then clean. Three charts, then a named WAV of version one.

Not a section writer. The song is already there. One note was wrong, and your ears had gone numb.
